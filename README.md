# MindCanvas v11 Final

GitHub-only update. No Supabase, SQL, RLS, login, environment-variable or Vercel-project changes.

## Fixed
- Every popup gets a visible × button, Cancel footer, outside-click close, and Escape close.
- Add new root pattern, sub-pattern or micro-pattern manually.
- Add a child pattern directly from a selected node.
- Existing Library, Questions, Connected Notes, deletion, permanent positions, zoom/pan, search, lock mode and PNG export remain.
- Auto-arrange was removed from the visible UI.
- Confirmed Undo and Redo, with a popup before any history state is applied.
- Four saved map styles: Sticky notes, Soft cards, Outline and Glass.
- Mind-map node hierarchy: blue pattern-family cards, orange sub-pattern cards, green micro-pattern cards and pink dashed question cards.
- Locked mode still prevents accidental node dragging and deletes remain confirmed.
